# 置信集合与保守外包区间结果表

本目录整理新随机种子验证的600条方法结果，不重跑估计，不改变任何原始接受分量、点估计、标准误或覆盖标记。完整置信集合是主要推断结果。保守外包区间仅作为需要连续区间时的附加报告，不替代完整集合。

## 统一报告规则

- 原始`score_components`逐字保留，不排序、合并、裁剪或选择某一个分量。
- 成功集合增加分量数、不连通、触下界、触上界和任一触边界标记。边界仅沿用既定参数空间[0.45,1.15]，判断容差为1e-9，不据此调整端点。
- 原集合总长度是各分量长度之和。保守外包下界为所有分量的最小下界，上界为最大上界，其长度包含原本被拒绝的分量间隙。
- 不连通和触边界不等于计算失败，不改变原来的失败率。失败集合的新增几何字段与标记缺失，另由`set_report_status`明确标为失败，不伪装成正常空区间。
- 外包覆盖率仅在模拟评价时计算，构造外包的函数不读取真值。原集合覆盖的参数必被外包覆盖，但外包不提供新的精确检验或更高估计精度。

## 最新验证的汇总

| 样本量 | 方法 | 完整集合覆盖率 | 完整集合平均总长度 | 外包平均长度 | 不连通数 | 触下界数 |
|---:|---|---:|---:|---:|---:|---:|
| 500 | 校准GAN | 93% | 0.14614 | 0.14917 | 2 | 2 |
| 500 | 经验法 | 93% | 0.14208 | 0.14616 | 2 | 2 |
| 500 | 同核plug-in | 92% | 0.12303 | 0.12303 | 0 | 0 |
| 2000 | 校准GAN | 95% | 0.06741 | 0.06741 | 0 | 0 |
| 2000 | 经验法 | 95% | 0.06679 | 0.06679 | 0 | 0 |
| 2000 | 同核plug-in | 95% | 0.06426 | 0.06426 | 0 | 0 |

每格100次。所有原始计算失败率为0；外包的覆盖率在本轮与完整集合相同。共4条标记结果，来自500样本的第29与第50次重复，各有校准GAN和经验法两种方法。完整集合的600行方法记录展开为604行分量记录。

## 文件与字段

| 文件 | 内容 |
|---|---|
| `results_with_reporting.csv` | 保留全部原始列，并追加统一报告字段 |
| `set_components.csv` | 一行一个原始分量，604行 |
| `summary.csv` | Wald、完整得分集合、保守外包的18组汇总 |
| `flagged_cases.csv` | 4条不连通或触边界结果，保留完整组件与外包端点 |
| `confidence_set_table.tex` | 单独保存的LaTeX结果表片段，未插入正文 |
| `manifest.json` | 来源文件及SHA-256、报告规则版本和固定容差 |
| `verification.json` | 原始数值、组件、覆盖、长度与来源完整性检查 |

新增字段使用`set_`和`conservative_hull_`前缀，避免覆盖原来的`component_count`、`score_length`和`boundary_truncated`等历史字段。`conservative_hull_gap_length`是外包填入的拒绝间隙长度，不能计作原集合总长度。

## 代码

`code/confidence_set_reporting.py`是无估计副作用的报告模块。`code/export_confidence_set_tables.py`负责为已完成验证生成这些新表；目标目录存在时拒绝覆盖。活动验证程序已接入同一模块，未来运行会输出相同字段。旧验证快照、旧结果表、论文正文和毕业论文冻结版保持不变。
