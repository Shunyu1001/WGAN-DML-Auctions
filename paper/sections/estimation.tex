\section{WGAN-GP Nuisance Estimation}

For the baseline implementation, the generator maps independent bidder-level
noise into a log valuation:
\begin{equation}
\widetilde L_{ij}=G_{\gamma}(Z_{ij}),\qquad
\widetilde V_{ij}=\exp(\widetilde L_{ij}),
\qquad Z_{ij}\overset{\mathrm{iid}}{\sim}\mathcal N(0,I).
\end{equation}
The same scalar generator is called independently for every bidder. This is
essential: a network that produces the entire bidder vector from one common
noise draw generally induces dependence across values and violates the
independent-private-values benchmark. Synthetic observables are constructed
using the same order-statistic map as the data,
\begin{equation}
\log\widetilde B_j=\max_{1\leq i\leq N}\widetilde L_{ij}.
\end{equation}
A critic compares standardized real and synthetic log maxima. Gradient-penalty
regularization imposes an approximate Lipschitz restriction on the critic. In
the pilot, each network has two hidden layers with 64 units, the bidder-level
noise dimension is eight, and every generator update follows five critic
updates. Checkpoints are selected using only the empirical Wasserstein distance
between real and generated maxima; the true reserve is not used in training or
model selection.

The trained generator induces estimates of the latent distribution, revenue
curve, and the smoothed maximum-bid moments required by the reserve-price
score. In the DML pilot, nuisance training is repeated separately within each
training fold and the score is evaluated only on the corresponding held-out
fold.

Under the baseline without covariates, the score's two local moments are also
directly estimable from observed maximum bids. The empirical-local ablation
therefore estimates $(A_h,G_h)$ on each training fold without using a WGAN.
Its reference for selecting among roots is the direct-inversion estimate.
This experiment diagnoses the local nuisance requirement; it does not by
itself establish a gain from retaining a global generative model.

A subsequent paired pilot implements a simple hybrid directly. Let $n_{-k}$
be the training-fold size and let $\widehat\eta^{(-k)}_{W,h}$ and
$\widehat\eta^{(-k)}_{E,h}$ denote the WGAN and empirical local moments.
Use the same mixture weight for the CDF and density:
\begin{equation}
\widehat\eta^{(-k)}_{C,h}
=(1-w_k)\widehat\eta^{(-k)}_{E,h}
+w_k\widehat\eta^{(-k)}_{W,h},\qquad
w_k=\frac{50}{n_{-k}+50}.
\label{eq:local-calibration}
\end{equation}
The fixed pseudo-count of 50 is specified before the evaluation runs; it is
not chosen using the true reserve, coverage, or evaluation-fold observations.
This post-fit calibration preserves the original WGAN-GP architecture and
loss. It changes only the moments supplied to the existing orthogonal score.
For fixed $h$, CDF signals lie in $[0,1]$ and density signals in
$[0,(\sqrt{2\pi}h)^{-1}]$. Hence the difference from the empirical nuisance
is uniformly $O(n^{-1})$, regardless of the WGAN fit, and the empirical-local
rate result continues to apply under the same overlap and root conditions.
This is an empirical-dominated safeguard, not a claim of improved asymptotic
efficiency. Whether the retained WGAN component improves finite-sample
performance is assessed against the empirical-only estimator and a
full-sample smoothed plug-in using the same kernel and bandwidth.

As a computational precursor, I also report a fold-averaged plug-in. Partition
the auctions into $K$ folds and train $\widehat F^{(-k)}$ outside fold $k$.
Define
\begin{equation}
\widehat r^{(-k)}_{\mathrm{PI}}
\in\arg\max_r r\{1-\widehat F^{(-k)}(r)\},
\qquad
\overline r_{\mathrm{FA}}=\frac{1}{K}\sum_{k=1}^K
\widehat r^{(-k)}_{\mathrm{PI}}.
\end{equation}
This construction measures the stability gained from sample splitting and
averaging independently trained generators. Because the held-out observations
do not yet enter an observation-level reserve score, $\overline r_{\mathrm{FA}}$
is not the orthogonal DML estimator.
